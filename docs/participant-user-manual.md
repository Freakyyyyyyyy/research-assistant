# 参与者使用手册

## 访问系统

研究人员会在实验开始前启动系统。默认地址：

```text
http://127.0.0.1:5173
```

页面无法访问或提示后端断开时，请告知研究人员。

## 页面

- **对话工作台**：提问、文献检索、选题指导和论文框架搭建。
- **论文库**：上传或导入 PDF，查看解析状态，运行快速分析或论文对比。
- **研究项目成果**：查看和导出已保存的卡片与报告。
- **系统设置**：由研究人员使用。

请确认当前项目名称与研究人员的指定一致。

## 对话

1. 进入“对话工作台”。
2. 选择现有会话，或点击“+”新建会话。
3. 在输入框中填写任务并发送。
4. 等待回复完成后继续操作。

生成过程中不要重复发送同一条消息。

## 文献检索

1. 在对话中输入检索需求。
2. 查看推荐文献和其他候选。
3. 需要后续使用的论文点击收藏，收藏后进入论文库。

## PDF 与论文精读

1. 在论文库中上传 PDF，或为已收藏的 arXiv 论文导入 PDF。
2. 等待解析任务完成。
3. 在对话工作台勾选“使用论文库精读”并选择论文。
4. 发送第一条精读问题。
5. 点击消息上方的 PDF 标签进入精读页。

精读页左侧为对话，右侧为 PDF 原文。

## 论文快速分析与对比

- 快速分析需要已完成文本解析的论文。
- 论文对比需要勾选 2–3 篇已解析论文。
- 生成结果保存在“研究项目成果”。

## 实验要求

- 按研究人员给定的顺序完成任务。
- 未经要求不要刷新页面、关闭服务或修改系统设置。
- 出现错误时，记录当时的页面和操作，然后告知研究人员。
- 完成全部任务后停止操作。
